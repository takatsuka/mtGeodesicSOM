# Sample data shipped with mtgeodesicsom

Load them with `mt.geodesicsom.datasets.load_sample(name)`, list them with `datasets.samples()`, or pass the name
to `python -m mt.geodesicsom --data NAME`.  Each file is a CSV with a header row: numeric columns are the
attributes, and one text column holds the class labels.

| name | samples | attributes | labels | missing values |
|---|---:|---:|---|---|
| `animals` | 16 | 13 binary (`small`, `medium`, `big`, `two_legs`, `four_legs`, `hair`, `hooves`, `mane`, `feathers`, `hunt`, `run`, `fly`, `swim`) | `animal` (16: one per animal) | none |
| `clusters` | 560 | 12 (`feature_1` … `feature_12`) | `cluster` (7 clusters, A–G) | none |
| `iris` | 150 | 4 (sepal and petal length and width, cm) | `species` (3) | none |
| `penguins` | 344 rows, 342 loaded | 4 (bill length and depth, flipper length, body mass) | `species` (3) | 2 rows have no measurements (empty cells); the loader skips them |
| `wine` | 178 | 13 (chemical analysis) | `cultivar` (3) | none |

## Sources and licences

These files are distributed with mtgeodesicsom for convenience; they are **not** covered by its AGPL licence.

* **animals.csv** — Kohonen's animal data: which of 13 attributes (is small / medium / big; has 2 legs / 4 legs /
  hair / hooves / mane / feathers; likes to hunt / run / fly / swim) each of 16 animals has, 1 = yes, 0 = no.
  Transcribed from Table 1 of H. Ritter and T. Kohonen, "Self-organizing semantic maps", *Biological Cybernetics*
  61(4):241–254, 1989, doi:10.1007/BF00203171 — please cite it when you use this data. The table records simple
  facts about the animals; the CSV transcription is part of mtgeodesicsom. As in the paper, owl and hawk have the
  same attributes, and so do horse and zebra; `mt.geodesicsom.datasets.animals(symbols=True)` adds the paper's
  "symbol" part that tells them apart.

* **clusters.csv** — synthetic: seven Gaussian clusters in 12 dimensions, generated by
  `mt.geodesicsom.datasets.clusters()` (seed 3). Part of mtgeodesicsom.

* **iris.csv** — R. A. Fisher's Iris data (1936), as distributed with scikit-learn (which corrects two values to
  match Fisher's paper). Public domain.
  R. A. Fisher, "The use of multiple measurements in taxonomic problems", *Annals of Eugenics* 7(2):179–188, 1936.

* **penguins.csv** — Palmer Archipelago (Antarctica) penguin data, from the `palmerpenguins` package by Allison
  Horst, Alison Hill and Kristen Gorman; licensed **CC0 1.0** (public domain). Columns `species`, `island`, `sex`
  and the four measurements; `NA` became an empty cell and the `year` column was left out.
  Please cite: Gorman K. B., Williams T. D., Fraser W. R., "Ecological sexual dimorphism and environmental
  variability within a community of Antarctic penguins (genus *Pygoscelis*)", *PLoS ONE* 9(3):e90081, 2014.
  doi:10.1371/journal.pone.0090081 — and Horst A. M., Hill A. P., Gorman K. B., palmerpenguins, 2020.
  doi:10.5281/zenodo.3960218

* **wine.csv** — the UCI Wine data set: results of a chemical analysis of wines grown in the same region of Italy
  from three cultivars, as distributed with scikit-learn. Licensed **CC BY 4.0** by the UCI Machine Learning
  Repository (attribution required). The class column is named `cultivar` (`cultivar 1` … `cultivar 3`).
  Aeberhard S., Forina M., "Wine" [dataset], UCI Machine Learning Repository, 1991. doi:10.24432/C5PC7J
